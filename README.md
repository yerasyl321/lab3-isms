# Репозиторий документации СМИБ

## Назначение
Хранение и версионирование документированной информации системы менеджмента информационной безопасности (СМИБ) учебной организации.

## Структура
- 01-politika/          — политика ИБ верхнего уровня
- 02-chastnye-politiki/ — частные политики
- 03-procedury/         — процедуры и регламенты
- 04-instrukcii/        — инструкции, шаблоны, чек-листы
- 05-zapisi/            — шаблоны записей

## Порядок внесения изменений
1. Создайте ветку с осмысленным именем.
2. Внесите изменения, сделайте коммит с информативным описанием.
3. Отправьте ветку в удалённый репозиторий.
4. Создайте запрос на слияние (pull request).
5. Назначьте рецензента, получите одобрение.
6. Выполните слияние в основную ветку.
7. При утверждении редакции установите тег.
